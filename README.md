# UTEP CLI — подключение к проекту ИИ-кодинга

---

## Что это

UTEP CLI — инструмент для **управляемой работы ИИ-агента** с задачами и целями в репозитории.

Он нужен, если вы хотите:

* чтобы агент **не терял контекст**
* чтобы задачи выполнялись **осмысленно**
* чтобы прогресс был **контролируем**
* чтобы ошибки **не останавливали работу**

---

## Установка

```bash
dotnet tool install -g utep
```

или локально в репо.

---

## Инициализация проекта

```bash
utep init
utep goal new --title "Моя цель"
utep goal open G-XXXX
```

---

## Базовый рабочий цикл (человек)

```bash
utep task new --title "Подготовить требования" --status Ready
# index.md обновляется автоматически после изменений
```

Время выполнения фиксируется автоматически между `task start` и `task attempt`/`task complete`; при необходимости можно задать `--minutes` вручную.

Дальше работает агент.

---

## Интеграция с ИИ-агентом

1. Положите в репозиторий:

   * `UTEP-SPEC.md`
   * `AGENT-RUNBOOK.md`
2. В system prompt агента добавьте:

   * “Ты обязан использовать utep CLI”
   * “Ты обязан следовать AGENT-RUNBOOK.md”
3. Агент работает **только через CLI**

---

## Просмотр состояния

```bash
utep goal status
utep goal tree
utep bottlenecks
utep report
```

---

## Почему это работает

* агент не “галлюцинирует” процесс
* все решения зафиксированы
* дерево задач всегда актуально
* параллельность и зависимости учитываются
* человек всегда может вмешаться

---

## Когда UTEP не нужен

* если у вас линейные задачи
* если агент работает одноразово
* если не нужен контроль процесса

---

## Философия

> *UTEP — это не про автоматизацию задач.*
> *Это про автоматизацию мышления под неопределённостью.*
