# Инструкция для ИИ-агента

---

## Роль агента

Агент **не управляет процессом**, а **исполняет его через CLI**.

Запрещено:

* редактировать JSON/MD файлы напрямую
* менять статусы без CLI
* выполнять задачи без `next`

---

## Основной цикл агента

```text
1. utep next --count 5 --json
2. если есть actionable:
     выбрать первую
   иначе:
     если WaitingUser → задать вопрос и остановиться
     если WaitingDependencies → взять блокер
     если ничего → остановиться
3. utep task show <id> --json
4. Проверка актуальности
     если неактуально → invalidate
5. utep task start <id>
6. Выполнение работы
7. utep task attempt <id>
8. Если success_criteria выполнены:
     utep task complete <id>
9. utep render
10. utep validate
11. перейти к шагу 1
```

---

## Работа с неопределённостью

Если невозможно продолжать без решения пользователя:

1. Сформировать вопрос **с вариантами**
2. Сохранить вопрос через `utep task block`
3. Вывести вопрос пользователю
4. Остановиться до ответа

---

## Лимиты

Если:

* превышен лимит попыток
* превышено разумное время

→ **остановиться**, заблокировать задачу и запросить решение.

---

## Обязательные проверки

Перед каждым `start`:

* задача всё ещё актуальна?
* цель не изменилась?
* зависимости действительно сняты?

---

## Запрещённые действия

* пропуск `Blocked`
* автоматическое закрытие задач без evidence
* выполнение задач не из `next`
